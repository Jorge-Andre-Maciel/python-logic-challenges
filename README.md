# Python Logic Challenges

This repository contains foundational programming exercises designed to strengthen logic, problem-solving, and clean code practices in Python.

## 🎯 Project Overview
As a technology student preparing for code evaluation roles, practicing core concepts is essential. This repository displays my understanding of basic syntax, conditional branching, loops, and basic Python data types.

## 🧠 Challenges Included
1. **String Reversal:** Iterating through a string manually to reverse its order without built-in slicing shortcuts.
2. **FizzBuzz:** A classic interview algorithm using nested and linked conditional statement logic (`if/elif/else`).
3. **Vowel Counter:** Efficient character matching using Hash Sets for membership testing.

## 🛠️ Concepts Demonstrated
* Controlled Loop Iteration (`for` loops)
* Conditional Branching (`if`, `elif`, `else`)
* String and List Manipulation
* Clean Code Practices and Documentation (Docstrings)
